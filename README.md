# Student Performance Prediction (AI Project)

## Overview
This project predicts whether a student will pass or fail based on academic and behavioral factors such as attendance, study hours, previous marks, assignments, and test scores.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression

## Dataset
The dataset contains student academic information and a final result (Pass/Fail).  
Data is used only for educational purposes.

## How It Works
1. Load student data from a CSV file
2. Convert Pass/Fail outcomes into numerical values
3. Train a Logistic Regression model
4. Evaluate model accuracy
5. Predict performance for new students

## Results
The model achieved high accuracy on the test dataset and can identify at-risk students early.

## Future Improvements
- Add more real-world data
- Include risk scoring instead of only Pass/Fail
- Try advanced models like Decision Trees or Random Forests
